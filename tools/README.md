# Cosmetic Designer

1. Start Live Server (VS Code "Go Live") and open `http://127.0.0.1:5500/tools/designer.html`.
2. Make skins, hats, faces and trails. The preview uses the real game drawing code.
3. **Save to project** (Chrome/Edge): pick the project root once; later saves are one click. This rewrites `src/data/custom-cosmetics.js`.
4. **Push to GitHub**: fill in repo, branch and a token under "GitHub settings", then one click. Or commit in VS Code.
5. Reload the game: new items show up in the shop, drops and the pass.
